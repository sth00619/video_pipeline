# Job 52 방향성 복구 재개 체크포인트

중단 시각: 2026-08-24 (Asia/Bangkok)

## 현재 상태

- 유료 Claude/Gemini/Fal 생성 작업은 실행 중이지 않다.
- 이번 중단 요청 이후 코드 수정과 실 API 재생성은 시작하지 않았다.
- Docker 서비스는 기존 상태로 유지했다. 재개 시 health check부터 다시 수행한다.
- Job 52 원본 49장과 문제 5장을 실제 산출물 기준으로 대조했다.
- 문제 5장의 인덱스는 `0`, `1`, `35`, `40`, `47`이다.
- 성공 방향 참고 이미지는 아래 폴더에 복사해 두었다.
  - `references/`: Job 52 성공 장면 2, 4, 8, 18, 29, 43
  - `problems/`: 문제 장면 0, 1, 35, 40, 47
  - `current_refs/`: 현재 파이프라인의 캐릭터·화풍 참조 자산

## 확인된 핵심 원인

1. 문제 장면의 이미지 프롬프트가 `Samsung Electronics PER 4x`, `HISTORICAL LOW?`, `PAST WINS...` 같은 문구를 이미지 모델에게 직접 쓰라고 요구했다.
2. 같은 장면 메타데이터에는 `no readable text`가 함께 있어 긍정·금지 지시가 충돌했다.
3. 최근 1분 작업 실행기는 캐릭터 시트 한 장만 명시적으로 전달했다. 이 경우 코드가 기본 화풍 참조 이미지를 병합하지 않아 Job 52의 성공 화풍·무대 밀도가 잠기지 않았다.
4. OCR 재시도 프롬프트는 글자만 지우지 않고 보드·화면·도표·화살표까지 전부 제거하도록 지시한다. 그 결과 성공 장면의 관제실·뉴스룸·반도체 공장 같은 정보 밀도까지 사라지고 교실·저울·빈 벽으로 퇴행했다.
5. 이미지 계보 지문이 참조 이미지의 파일 경로만 포함하고 파일 내용 해시는 포함하지 않는다. 화풍 참조가 바뀌어도 이전 PNG를 잘못 재사용할 수 있다.
6. 승인 1분 대본의 `screen_texts`가 모두 빈 배열이라 결정론적 정확 문구 합성 경로가 실제로 검증되지 않았다.

## 재개 직후 구현 순서

1. `gemini_provider.py`에 기본 화풍 참조 전용 로더를 추가한다.
2. 사용자가 캐릭터 시트를 지정해도 `캐릭터 시트 + 승인 화풍 참조`를 병합하도록 `images_worker.py`를 수정한다.
3. Job 52 성공 장면을 작업 번호와 무관한 승인 화풍 참고 자산으로 등록한다. 코드에는 Job 52 조건 분기를 넣지 않는다.
4. OCR 재시도는 감지된 문자 표면만 깨끗하게 만들고, 관제실·화면·도표·소품·전경/중경/배경 정보 밀도는 보존하도록 좁힌다.
5. 이미지 계보 버전을 올리고 참조 파일 SHA-256을 지문에 포함한다. 현재 버전 이미지의 무조건 레거시 재사용을 막는다.
6. 시각 QA에 다음을 함께 검사하도록 보강한다.
   - Job 52 성공 방향의 편집 만화 화풍과 장면 밀도
   - 대사와 장면의 의미 일치
   - 허용 목록 밖 한국어·영어·숫자·의사문자
   - 동일 교실/저울/캐릭터 포즈 반복
7. 대본 생성 규칙에서 정보형 핵심 장면은 대사 원문 또는 검증 사실의 정확 부분 문자열을 `[화면 문구]` 1~2개로 내도록 보강한다. 번역·요약·새 수치는 계속 금지한다.
8. 단위 테스트 후 Docker를 다시 빌드한다.
9. Job 52 자체 이미지를 덮어쓰지 않고 새 작업 ID로 1분 대본·TTS 계보를 사용해 새 이미지 세트를 생성한다.
10. 접촉 시트로 사람 검수한다. 화풍·정보 밀도·텍스트 정확성이 통과하지 않으면 Fal과 조립을 시작하지 않는다.
11. 이미지 승인 후에만 초반 Fal을 실행하고, 사물/캐릭터 국소 움직임과 전체 화면 지글링 여부를 필름스트립으로 검사한다.

## 유지해야 할 세 목표

- 목표 1: 승인 대본 분량을 실제 선택 음성의 TTS 시간으로 보정하고, 자막 청크와 이미지 전환 의미 단위를 일치시킨다.
- 목표 2: Fal은 초반부에 영상 길이 비례로 적용하되 화면 전체 지글링이 아니라 캐릭터·사물의 국소 움직임만 허용한다.
- 목표 3: 무문자화가 목적이 아니다. 필요한 문구는 승인 대본/검증 사실 그대로 결정론적으로 렌더링하고, 오탈자·이탈자·임의 영문만 차단한다.

## 재개 명령

사용자가 `체크포인트에서 계속 진행해줘`라고 말하면 이 파일을 먼저 읽고, 위 구현 순서 1번부터 계속한다.
