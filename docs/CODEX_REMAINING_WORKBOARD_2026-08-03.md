## 절대 변경하지 않는 규칙

- 새 기사형·정보형 작업이 기존 일반형, Claude 대본, TTS/자막, Fal 기능을 대체하지 않는다.
- 기사형은 원본 기사 캡처·하이라이트·출처를 보존하고, Fal에 보내지 않는다.
- 일반형은 읽을 글자와 숫자를 넣지 않으며, 한국형 공간·상황·배경의 다양성을 우선한다.
- 정보형은 대본 의미와 연결된 짧은 문구만 물리적 화면·표지판·칠판에 배치한다. 임의 정확 수치는 만들지 않는다.
- Fal은 텍스트 없는 일반형에서만 명시 선택한다. 본편의 이미 생성된 장면을 자동 교체하지 않는다.
- 썸네일은 본편 품질 승인을 통과하기 전에는 시작하지 않는다.
