# 시장 설명 장면 시각 기준

아래 이미지는 대본·지표·캐릭터·배경이 하나의 장면에서 읽히는지 수동으로 판정하기 위한 시각 기준이다. 투자 추천이나 실제 시장 전망이 아니며, 실제 운영 영상의 값은 검증 사실과 결정론 렌더링으로만 넣는다.

## 공통 판정 기준

- 마스코트는 `goldie_sheet_v1.png`의 둥근 금화 실루엣, 점각 림, 큰 흰자 눈, 네이비 정장, 흰 장갑, 갈색 구두를 유지한다.
- 화풍은 굵고 유기적인 어두운 외곽선, 부드러운 손그림 2단 셀 셰이딩, 따뜻한 스튜디오 조명, 케이블·카메라·아날로그 콘솔 같은 촉각적 소품을 사용한다. 네온 핀테크 대시보드, 광택 3D, 지폐·문서형 캐릭터는 반려한다.
- 한 장면에는 하나의 넓은 물리 벽면 그래프만 둔다. 떠 있는 UI 카드, 하단 자막, 독립 숫자 상자, 보조 모니터는 사용하지 않는다.
- 대본의 지표·용어·수치가 필요하면 모두 같은 벽면에 합성한다. 실제 수치·등락률·가격은 생성 모델에 맡기지 않고 검증 사실과 Pillow 렌더러를 이용한다.
- `매수 신호`와 `매도 신호`는 교육용 설명 상태이며, 실제 종목·실시간 데이터·개인화된 투자 추천을 의미하지 않는다.
