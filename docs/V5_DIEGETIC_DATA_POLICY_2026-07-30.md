# V5 장면 내 데이터 표현 정책

## 목적

V5는 카툰 배경 위에 범용 카드나 대시보드를 덧붙이는 작업이 아니다. 지도 위
기상 라벨, 금속 경보 명패, 계기판 눈금, 칠판 분필, 계산대 전광판처럼 원래
장면에 존재하는 사물 안에 정보를 넣어 경제 설명의 구체성을 높인다.

## 세 데이터 층

| 층 | 생성 주체 | 허용 범위 | 사실 취급 |
| --- | --- | --- | --- |
| 장식 정보 | 이미지 모델 | 영어 라벨, 눈금, 수식, 기호, 배경 그래프 | 장식만 가능 |
| 검증 지표 | Pillow/SVG | 뉴스 원문에 존재하는 수치와 단위 | 출처 URL과 함께 사실로 표시 |
| 검색어 트렌드 | NAVER API HUB + Pillow/SVG | API 원본 `ratio` 시계열 | 상대 검색 관심도만 표시 |

`ratio`는 절대 검색량ㆍ주가ㆍ등락률이 아니다. 지표명과 원본 값을 보존하고,
투자 성과로 해석하는 문구를 자동 생성하지 않는다.

## 금지 형태

- 장면 위에 떠 있는 사각형 UI 카드ㆍ대시보드ㆍPIPㆍ독립 LCD
- 빈 모니터ㆍ빈 칠판ㆍ빈 그래프를 후처리용 자리로 남기는 방식
- 검증 사실 원문이나 NAVER 응답에 없는 숫자ㆍ반올림되지 않은 추정치
- 마스코트 얼굴ㆍ손ㆍ자막 안전영역을 침범하는 데이터 라벨

## 현재 구현 상태

1. `visual_data_pack.json`은 검증 뉴스 지표와 NAVER 검색어 트렌드를 분리해
   수집하고 출처와 타입을 보존한다.
2. `checkout_total`은 계산대 LCD 내부만 교체한다.
3. 날씨 지도 템플릿은 NAVER 검색어 트렌드의 마지막 원본 점을 지도 라벨로
   직접 표기한다. 별도 상자를 만들지 않는다.
4. 실제 영상 렌더링 전에는 장면별 소품 좌표, 마스코트 안전영역, 자막 영역을
   사람이 검토한다. 자동 게이트는 충돌 시 렌더를 차단하는 방향으로 확장한다.

## 보류한 장기 과제

검증 수치를 이미지 모델 프롬프트에 전달해 모델이 처음부터 장면 속 글자로
그리게 하는 실험은 아직 시작하지 않는다. 현재 단계에서는 이미지 모델의
장식 문자와 Pillow/SVG의 검증 수치를 분리해 정확도와 재현성을 유지한다.
