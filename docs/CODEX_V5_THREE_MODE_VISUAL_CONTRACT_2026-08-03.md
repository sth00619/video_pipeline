# V5 3종 시각 계약

작성일: 2026-08-03  
상태: 구현·사전검증 완료, 유료 이미지 생성 대기

## 목적

기사형·상황형·정보형이 같은 화풍 계약과 산출물 계보를 공유하면서도 반복되지 않게 한다. 영상 위에 별도 요약 상자나 말풍선을 얹지 않고, TTS 원문과 100% 같은 ASS 자막만 영상 텍스트로 사용한다.

## 공통 고정 규칙

- V5 스타일: 두꺼운 검정 잉크 윤곽선, 강한 셀 셰이딩, 채도 높은 카툰 방송 화풍. 수채화·부드러운 그라데이션·포토리얼은 금지한다.
- 캐릭터: 제공된 첫 번째 캐릭터 참조 이미지를 정본으로 사용한다. 갈색 페도라 1개, 네이비 슈트, 흰 장갑, 둥근 금화 얼굴·눈·볼·외곽선을 모든 캐릭터 장면에서 유지한다. 안전모·학사모·턱시도·나비넥타이·흰 스티커 테두리는 금지한다.
- 텍스트: 말풍선, 캡션칩, 제목카드, 하단 배너, 떠 있는 UI 박스를 생성·합성하지 않는다. 정보형의 영문 핵심 문구만 대본 의미에 맞춰 하나의 물리 소품 표면에 직접 들어간다.
- 수치: 정보형·수치형 이미지의 정확 수치, 퍼센트, 통화, 축 눈금, 데이터 라벨을 전면 사용하지 않는다. 상승은 빨간 방향선, 하락은 파란 방향선, 비중은 숫자 없는 원형 조각, 흐름은 무라벨 화살표·막대·선으로 설명한다.
- 한국형 맥락: 한국 관련 대본은 서울형 업무지구·증권사·항만·반도체 산업단지·국내 대형마트처럼 알아볼 수 있는 공간과 소품을 사용한다. 실제 기업 로고, 깨질 수 있는 한글, 가격표 숫자는 생성하지 않는다.

## 계보와 검수

- 각 생성 장면의 `v5_render_contract`에 `visual_mode_contract`, 화풍 버전, archetype, 물리 표면, 대본 의미 시각 계획을 기록한다.
- 억제된 말풍선·요약칩·수치 오버레이는 `overlay_provenance`에 억제 사유를 남긴다.
- 9장 테스트는 기사형·상황형·정보형을 정확히 3장씩 요구하고, 기사 출처·이미지 파일·Gemini 비용 상한을 사전검증한다.
- 이미지는 생성 뒤 캐릭터 정체성·텍스트 표면 결합·대본 의미·구도·3종 분포 기준으로 한 장씩 판정한다. 이 단계가 승인되기 전 Kling, MP4 조립, 썸네일로 진행하지 않는다.

## 확인 결과

`run_visual_mix_nine_scene_preflight.py`는 현재 3·3·3 분포, 기사 캡처 3건, Gemini 6장, 테스트 예산 ₩5,000 이내(추정 ₩1,239)를 확인한다. 이 사전검증은 API 호출·이미지 생성·Kling·MP4 조립을 수행하지 않는다.
