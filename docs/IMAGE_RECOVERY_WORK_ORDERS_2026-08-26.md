### 원인과 변경

`FICTIONALIZED_LABEL_MAP`의 단음절 금/은에 공백 제거 후 substring 매칭을 적용해 조사와 합성어를 오인했다.
`fictionalized_labels`가 삼성전자를 Gold로 치환한 것이 아니다. `core_entities`에 잘못 들어간 금/은이
실명 영문 매핑을 통해 Claude 입력에 전달됐다. OCR나 프롬프트 뒤쪽 QA만 강화해서 해결할 수 없는 입력 오염이다.

- 회사명 내부 띄어쓰기 허용: `SK 하이닉스` ↔ `SK하이닉스`.
- 실제 원자재 명사 보존: `금 가격`, `금은`, `은은`, `금과 은을`, `금값`, `은현물`.

## 5. WO-IMG-01 — 정보성/장식성 텍스트 계약

승인된 정책이며 아직 전역 적용 완료는 아니다. 기존 구현은 수치/비수치 분기이므로 변경이 필요하다.

| 종류 | 책임 | 보존할 시각적 성격 |
|---|---|---|
| 정보성: 회사명, 지수명, 금액, 지수값, 배수, 인용 | 승인 원문 → Pillow/FFmpeg 결정론 합성 | 기존 장면의 자연스러운 물리 표면, 원근, 명암, 정보 밀도 |
| 장식성: 승인된 짧은 한글/영어 | 실측된 크기/길이/문자체계 조건에서만 모델 생성 후보 | 단어 자체가 새로운 사실을 주장하면 정보성으로 재분류 |
| 근거 없는 숫자·오탈자·의사문자 | 생성/최종 승인 모두 거부 | 글자가 존재한다는 이유로 실패 처리하지 않음 |

모든 장면을 동일한 빈 판넬, 숫자 카드, 스튜디오로 만들지 않는다. 기존 필수 소품의 표면만 텍스트 레이어와 분리한다.
결정론 렌더도 잘못된 입력, 폰트 누락, 잘림, 원근, 가림 문제까지 100% 해결하지는 않는다. 원문 hash, glyph 커버리지,
quad 안쪽 배치, 합성 영역, 최종 해상도 가독성을 따로 검사한다. 외부 생성비가 없다는 것과 전체 비용이 0이라는 것은 다르다.
무조건적인 한국어 금지/전역 무문자화는 적용하지 않는다. 측정 전 장식 문구도 기본적으로 결정론 경로에 둔다.

- lease는 조회한 원격 SHA를 명시해 사용한다. 원격이 움직였으면 중단하고 다시 조정한다.
