# 롱폼 카툰 이미지: 배경·수치 배치 문법

분석 대상은 제공된 1920×1080 레퍼런스 영상의 대표 프레임이다. 이 문서는 특정 채널의 로고·캐릭터·개별 장면을 복제하기 위한 것이 아니라, 우리 채널의 노란 코인 캐릭터와 독자적인 배경에 적용하는 화면 문법이다.

## 공통 화면 구조

- 16:9 화면에서 하단 자막 바는 약 10~14%를 차지한다. 위쪽 86~90%만 장면과 정보에 사용한다.
- 캐릭터는 장면에 따라 화면 높이의 약 35~55%를 차지하며, 항상 같은 쪽·같은 크기로 고정하지 않는다.
- 한 컷에는 `핵심 주장 1개 + 이를 검증하는 숫자/라벨 1개 묶음`만 둔다. 숫자가 여러 개면 공통 단위와 기준을 바로 표시한다.
- 배경은 설명 대상의 실제 맥락으로 선택한다. 공장·항만·매장·교실·방송 스튜디오·지도·문서·연구실·계약 현장 등에서, 수치가 해당 장소의 물건에 붙어 있어야 한다.

## 수치가 놓일 장소

| 장면 | 권장 정보 표면 | 피해야 할 방식 |
| --- | --- | --- |
| 공장·물류 | 기계에 끼운 점검표, 컨테이너 검사 태그, 운송장 | 이유 없는 대형 칠판 |
| 지도·정책 | 지도 지역에 붙은 구름 라벨, 표지판, 국기 옆 문서 | 그래프가 없는 빈 지도 패널 |
| 시장·경기 | 거래표, 가격표, 심판 점수 카드, 매장 영수증 | 네온 대시보드 또는 무관한 차트 |
| 분석·비교 | 책상 보고서, 저울 추, 계약서, 클립보드 | 설명 없는 빈 원·빈 보드 |
| 출처·근거 | 화면 전체의 보고서/기사 발췌, 밑줄·주석 | 캐릭터와 별개로 떠 있는 카드 |

## 글자·말풍선

- 이미지 모델에는 읽을 글자를 요구하지 않는다. 배경/소품/빈 표면만 만들고, 한글·숫자·그래프는 검증된 후처리로 넣는다.
- 말풍선은 상단 1/3의 빈 공간에 두고, 흰색 불규칙 버스트와 얇은 검정 외곽선, 검정 굵은 글자로 처리한다. 글자 외곽선은 최소화해 뭉개지지 않게 한다.
- 일반 설명은 검정 또는 짙은 회색, 위험·증가 같은 단일 강조만 절제된 빨강 또는 채널 노랑을 쓴다. 무지개색 지표와 과도한 글로우는 쓰지 않는다.

## 그래프 검증 규칙

1. 정책 비율·상한·전후 비교는 시계열이 아니라 동일 기준의 막대/저울/비교 카드로 표현한다.
2. 시계열은 날짜 순서·동일 단위의 관측값·축 범위가 실제 데이터에 있을 때만 사용한다.
3. 모든 값은 수집된 payload에서 오며, 수집 시각·단위·기준값을 보존한다. 임의 수치나 무관한 시장 지수로 대체하지 않는다.
4. 차트의 안전 영역은 캐릭터, 말풍선, 소품과 겹치지 않는 독립된 물리 표면이다. 축·눈금·값·범례는 그 안에서만 그린다.

## 파이프라인 반영

`art_direction.py`는 data 장면마다 고정 칠판 대신 `monitor`, `inspection_clipboard`, `trading_ticket`, `ledger_card`, `desk_report`, `map_cloud`, `product_label` 중 이야기와 장면군에 맞는 정보 표면을 고른다. 이미지 생성은 그 표면을 빈 상태로 만들고, `market_charts.py`와 오버레이 단계가 검증된 한글·수치·축·그래프를 그 안에 렌더링한다.
