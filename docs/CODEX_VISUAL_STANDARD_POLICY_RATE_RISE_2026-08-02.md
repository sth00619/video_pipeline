# 기준금리 인상 장면 시각 기준

기준 이미지: `artifacts/gemini_pilot/reference_prototypes/bok_policy_rate_rise_visual_standard_v1.png`

이 기준은 실제 Gemini 산출물이 아니라 사용자가 제공한 영상 레퍼런스와 현재 대본을 바탕으로 만든 수동 검수용 시각 프로토타입이다. 실제 운영 이미지는 Gemini 배경과 Pillow 사실 합성으로 만든다.

## 장면의 필수 의미

- 시청자는 한눈에 `기준금리`가 `2.50%`에서 `2.75%`로 올라갔고 변화량이 `+0.25%p`라는 사실을 읽을 수 있어야 한다.
- 세 수치와 상승선은 모두 같은 넓은 벽면 그래프 안에 있어야 한다. 프레임 위 카드, 하단 자막, 독립 UI 상자, 지도 위 레이블은 허용하지 않는다.
- 상승선은 낮은 좌측 원형 시작점에서 높은 우측 원형 종료점으로 연결되어야 하며, 마스코트는 종료점 또는 상승선을 가리킨다.
- 배경의 제어실 조명·그래프 벽·마스코트·지표가 같은 원근과 광원 안에 있어야 한다.

## 캐릭터 기준

- `goldie_sheet_v1.png`의 둥근 금화 몸체, 점각 림, 큰 흰자 눈, 짙은 눈썹, 볼터치, 네이비 정장, 흰 장갑, 갈색 구두를 유지한다.
- 지폐·문서·사각 카드·태블릿·로봇 형태나 사실적인 3D 재해석은 반려한다.

## 사실성 경계

Gemini에는 검증 수치나 한글 문구를 보내지 않는다. `기준금리`, `2.50%`, `2.75%`, `+0.25%p`와 상승선의 의미는 검증 사실 원문을 통과한 Pillow 렌더러가 최종 PNG의 지정 벽면에만 합성한다. 따라서 모델이 만든 가짜 문자나 수치가 실제 대본과 섞이지 않는다.
