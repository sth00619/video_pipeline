# 카툰 경제 롱폼 레퍼런스 프레임 문법

## 목적

제공된 레퍼런스는 특정 채널의 로고·캐릭터·문구를 복제하는 대상이 아니다. 여기서 추출하는 것은 **카툰 경제 설명을 한 프레임 안에서 읽히게 만드는 연출 문법**이다. 우리 파이프라인은 노란 코인 마스코트, 자체 배경, 자체 색상과 후처리 한글을 사용한다.

## 프레임별 분석

| 프레임 | 서사 역할 | 캐릭터 비중/위치 | 정보 장치 | 읽는 순서 | 파이프라인 패턴 |
| --- | --- | --- | --- | --- | --- |
| 항만 폭풍·경보 | 위기 훅 | 중앙 하단, 약 45~50% 높이 | 상단 큰 말풍선 하나 | 위기 단어 → 캐릭터 표정 → 항만 원인 | `field_alert` |
| 무인 계산대·가격 | 생활형 수치 설명 | 좌측, 약 55~65% 높이 | 말풍선 + 계산대 화면 | 반응 → 큰 금액 → 왜 다른가 | `price_shock` |
| 뉴스 스튜디오·관세 구름 | 숫자 비교 | 우측, 약 45% 높이 | 지도 위 구름 두 개 | 기준 수치 → 비교 수치 → 화살표 | `news_map` |
| 좌우 국가 비교 | 정책 차이 | 중앙, 약 30% 높이 | 양쪽 카드/조명 | 제목 → 좌측 불이익 → 우측 보호 | `split_comparison` |
| 칠판·세계 공급망 | 구조 설명 | 우측, 약 40~45% 높이 | 넓은 칠판 하나 | 관계도 → 핵심 질문 → 강의자 | `chalkboard_lesson` |
| 교실·말풍선 | 개념 진입 | 우측, 약 40% 높이 | 좌상단 말풍선 하나 | 질문 → 칠판의 근거 → 캐릭터 | `chalkboard_takeaway` |
| 데이터 관제실·지도 | 지역/산업 데이터 | 좌측, 약 45~50% 높이 | 중앙 지도 + 보조 모니터 | 지도 포인트 → 핵심 지표 → 분석가 | `data_lab` |
| 계산실·저울 | 규칙/계산 설명 | 좌측, 약 35~40% 높이 | 우측 큰 저울/수치 | 비교 대상 → 비율 → 판단 | `comparison_board` |

## 공통 규칙

1. **하나의 프레임에는 하나의 질문만 둔다.** 말풍선은 반응 또는 질문 하나, 데이터 패널은 같은 질문의 근거만 표시한다.
2. **캐릭터는 장식이 아니라 시선 유도 장치다.** 포즈와 손끝이 수치·지도·칠판을 가리키며, 전신은 보통 프레임 높이의 42~55%를 차지한다. 비교형만 중앙 28~35%까지 축소한다.
3. **정보면은 캐릭터 반대편에 둔다.** 캐릭터와 텍스트가 겹치지 않으며, 장면마다 좌우를 번갈아 사용한다.
4. **수치는 '제목 + 값 + 의미'의 3층만 사용한다.** 예: `코스피 종가` / `8,864.24` / `▲ 137.64 (+1.58%)`. 한 패널의 수치를 2개 이상 경쟁시키지 않는다.
5. **텍스트는 생성 모델이 쓰지 않는다.** 배경은 빈 말풍선·빈 보드·빈 카드까지만 만들고, 한글·수치·기호·출처는 검증 데이터와 폰트 렌더러가 합성한다.

## 초기 타이포·색상 토큰

| 용도 | 크기 기준 (1080p) | 색상 | 외곽선/배경 |
| --- | --- | --- | --- |
| 질문 말풍선 | 80~104px, 최대 두 줄 | 노랑 `#FFD230` 또는 흰색 | 검정 5~7px, 흰 말풍선 |
| 핵심 수치 | 66~90px | 상승 `#FF5A4F`, 하락 `#54BFFF`, 강조 `#FFD230` | 검정 3~5px |
| 패널 제목 | 38~52px | 흰색 또는 짙은 남색 | 무광 패널, 1~2px 테두리 |
| 보조 설명 | 26~34px | 청회색 또는 주황 | 외곽선 최소화 |
| 칠판 필기 | 40~58px | 분필 흰색/노랑 한 색만 | 카드 없이 실제 칠판 위 |

기본 팔레트는 남색 `#071A3A`, 노랑 `#FFD230`, 경고 빨강 `#FF5148`, 상승 청록 `#3DD6B4`, 하락 하늘색 `#54BFFF`, 종이 크림 `#FFF8E8`이다. 빨강·노랑·청록은 한 장에서 최대 두 가지 강조색만 쓴다.

## 구현 상태와 다음 반복

### 이번 반영

- `art_direction.py`에 18개 장면 계열의 `reference_composition`을 추가했다.
- 데이터 장면은 모두 캐릭터를 좌측에 고정하지 않고 `data_lab`(캐릭터 우측/보드 좌측), `factory_panel`(캐릭터 좌측/보드 우측), `market_scoreboard`를 순환한다.
- 프롬프트도 실제 배치 방향을 읽어 빈 정보면을 예약한다. 따라서 캐릭터와 보드가 같은 쪽을 점유하지 않는다.

### 다음 반복 순서

1. 실제 롱폼 1편을 생성해 장면 8~12장을 추출한다.
2. 위 표의 패턴별로 `캐릭터 면적`, `말풍선 면적`, `글자 최소 높이`, `수치 행 수`를 자동 QA 지표로 저장한다.
3. 시청 화면 기준으로 질문 색상·수치 색상·외곽선 두께를 조정한다.
4. 수급·등락률·지수·비교·비중·정책 타임라인을 각각 다른 데이터 보드 템플릿으로 확장한다.

## 금지 규칙

- 모든 데이터 장면을 동일한 대시보드 카드로 만들지 않는다.
- 숫자만 화면 중앙에 띄우거나, 말풍선과 수치 보드를 한 구역에 겹치지 않는다.
- 생성 모델의 가짜 한글·가짜 숫자를 승인하지 않는다.
- 외부 채널의 로고·워터마크·캐릭터·고유 문구를 재현하지 않는다.
