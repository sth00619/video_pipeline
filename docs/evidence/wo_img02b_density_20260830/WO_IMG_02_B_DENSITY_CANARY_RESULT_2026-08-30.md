# WO-IMG-02-B — 화풍·구성 밀도 레이어 실증 결과

## 1. 결론

`composition_density_profile`은 공통 운영 프롬프트에 실제로 전달됐고 네 요청 모두 Pro Priority HTTP 200을 받았다. 그러나 결과는 archetype마다 달랐다.

- scene15·28: 이전 after보다 밀도가 뚜렷하게 회복됐다.
- scene07: 장비와 깊이는 늘었지만 Job52보다 단순하고, “두 기업을 제외해도”라는 의미가 충분히 직접 읽히지 않는다.
- scene00: Job52의 책장·책상·교실 깊이가 복구되지 않았다. 밀도 개선 실패다.

따라서 이번 구현은 **공통 구조와 일부 archetype의 유효성을 확인한 단계**다. 모든 archetype의 품질 하한을 확보했다고 판단하지 않으며, 사용자 육안 승인 없이 확대하지 않는다.

## 4. 자동 게이트와 육안 판정 분리

| scene | HTTP | 자동 text gate | 자동 surface gate | 육안 밀도 판정 | 최종 판정 |
|---:|---|---|---|---|---|
| 00 | 200 | pass | fail | 이전과 비슷하거나 더 단순, Job52 미달 | 거절 |
| 07 | 200 | pass | fail | 이전보다 개선, Job52 미달 | 부분 개선 |
| 15 | 200 | pass | fail | 이전 대비 뚜렷한 개선, Job52 수준 이상 | 육안 통과·표면 계약 보류 |
| 28 | 200 | pass | fail | 이전 대비 뚜렷한 개선, Job52와 유사 | 육안 통과·표면 계약 보류 |

자동 text gate 4/4 통과는 육안 품질 합격을 뜻하지 않는다. 반대로 surface gate 0/4는 화면이 모두 휑하다는 뜻도 아니다. 현재 표면 검출기가 실제 생성 구도의 물리 표면을 안정적으로 attestation하지 못한 별도 문제다.

탐색 OCR은 scene15의 `엇갈림`만 정확 토큰으로 찾았다. scene00·07·28은 육안상 승인 문구가 정확하지만 축소 OCR이 놓쳤다. 이는 WO-IMG-01/02의 OCR 재현율 트랙이 아직 완료되지 않았다는 추가 증거다.

## 5. 장면별 판정

### scene00 — 실패

`삼성전자`, `SK하이닉스`는 정확하고 캐릭터 얼굴·팔다리도 정상이다. 하지만 Job52에 있던 서가, 책상, 좌석, 다층 교실 배경이 사라졌다. 저울과 칠판만 크게 남아 `min_background_elements` 지시가 실제 픽셀 결과의 밀도 하한으로 이어지지 않았다. 문구도 접시 위의 명확한 팻말보다 접시 앞에 떠 있는 인상이 강하고 surface gate가 실패했다.

### scene07 — 부분 개선

이전 after의 거대한 빈 화면 하나보다 서버랙, 관, 콘솔, 용기, 좌우 소형 화면이 늘었다. `삼성전자`, `SK하이닉스`, `코스피`도 서로 다른 화면에 정확히 배치됐다. 다만 중앙 화면 비중이 여전히 크고, 두 빈 용기가 어느 기업을 뜻하는지 직접 연결되지 않아 Job52의 “두 기업을 제외” 의미 전달력에는 못 미친다.

### scene15 — 밀도 개선 확인

상승/하락의 초록·빨강 색 대비, 다중 모니터, 조명, 기어, 균열이 근경·중경·원경을 만든다. `엇갈림`, `SK하이닉스`가 정확하고 대괄호·따옴표가 없다. 이번 네 장 중 밀도 프로필 효과가 가장 분명한 표본이다. 다만 자동 surface gate 실패 때문에 운영 자동 승인 후보로 올리지는 않는다.

### scene28 — 밀도 개선 확인

다중 모니터 벽, 콘솔, 경광등, 배선이 위기 관제실 구도를 회복했다. `대형주`도 정확하고 원본 확대 육안에서 추가로 읽을 수 있는 문자·수치는 확인되지 않았다. 이전 after의 절반이 빈 모니터 벽보다 확실히 개선됐다. 자동 surface gate는 실패했다.

## 7. 후속 정정 — WO-IMG-02-C 재감사 결과

이 절은 기존 판정 이력을 지우지 않고, 당시 보고 범위가 놓친 사항을 명시한다.

1. scene00은 밀도뿐 아니라 저울과 칠판이 같은 비교 개념을 중복할 위험을 검토했어야 했다.
2. scene07은 `143조 원`이 결정론 렌더 대상으로 분리됐지만 당시 실행기가 실제 Pillow 최종 합성을 하지 않았다. 따라서 핵심 결론 수치가 없는 raw를 “부분 개선”이라고만 쓴 것은 불충분했다.
3. `surface gate 0/4`는 다음 우선순위 정도가 아니라 최종 자동 승인 불가 상태였다. 동시에 당시 실행기가 다중 생성 문자 표면을 단일 결정론 표면 검출기로 검사했으므로, 0/4를 모두 같은 원인의 “빈 표면 없음”으로 해석할 수도 없다.
4. scene15는 후속 확대 육안에서 `엇갈림`이 두 번 표시된 것이 확인돼 허용 횟수 1회를 위반했다.
5. scene28은 밀도는 회복됐지만 다른 장면보다 날카로운 눈매와 강한 적색 채도가 나타났다. 이를 화풍·팔레트 일관성 축에서 별도 평가하지 않았다.

WO-IMG-02-C의 현재 운영 계약으로 같은 raw를 재최종화한 결과 scene00은 `PER 4배`가 잘못된 화면 중앙에 떠서 거절, scene07은 안전한 `summary_monitor`를 찾지 못해 거절됐다. scene15·28도 위 이유로 승인하지 않았다. 자세한 계보와 판정은 `docs/evidence/wo_img02c_comprehensive_20260830/WO_IMG_02_C_COMPREHENSIVE_RECHECK_AND_CANARY_2026-08-30.md`를 기준으로 한다.
