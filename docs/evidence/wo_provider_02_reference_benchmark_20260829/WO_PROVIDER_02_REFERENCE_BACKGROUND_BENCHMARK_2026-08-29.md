# WO-PROVIDER-02 레퍼런스 배경 스타일 벤치마크

## 범위와 한계

사용자 제공 `reference_all_frames.tar.gz`의 69개 1280×720 프레임을 모두 육안 검토했다. 이 자료는 15초 간격 표본으로 보이므로 약 17분 영상의 장면 전환 전수를 추출했다고 주장하지 않는다. 분류 대상은 배경·구도·정보 표현 방식이며 초록 카드 캐릭터의 디자인·실루엣·색상은 우리 금화 캐릭터에 이전하지 않는다.

## 핵심 결론: 유형과 텍스트 전략은 분리해야 한다

레퍼런스는 하나의 고정 배경을 반복하지 않는다. 대본의 설명 기능에 따라 배경 유형을 선택하지만, 텍스트는 별도 레이어 규칙을 반복한다.

1. 긴 문장: 하단 검은 띠 자막. 승인 내레이션 원문을 별도 합성한다.
2. 짧은 강조어: 말풍선·배너·표지판. 장면당 제한된 수만 크게 표시한다.
3. 수치·정보 라벨: 모니터·칠판·가격표·간판 같은 의미 있는 물리 표면에 배치한다.
4. 실제 증거: 뉴스·차트·기업 화면은 캡처 자산을 삽입한다.

따라서 `교실형이면 항상 말풍선`, `관제실형이면 항상 수치`처럼 유형과 문자열 정책을 한 몸으로 고정하면 안 된다. 장면 분류기는 배경·소품·카메라 구도를 선택하고, 텍스트 라우터는 승인 대본에서 추출된 정보의 길이·성격·근거에 따라 독립적으로 합성 방식을 선택해야 한다.

## 현재 파이프라인과의 차이

| 항목 | 레퍼런스에서 관찰 | 현재 공통 경로 | 보완 방향 |
|---|---|---|---|
| 긴 내레이션 | 하단 자막으로 완전 분리 | 승인 내레이션이 TTS·자막 SSOT | 유지. 이미지 모델에 긴 문장을 쓰게 하지 않음 |
| 짧은 강조어 | 말풍선/배너 직접 표현 | 승인 목록·strict OCR 레인 존재 | 평문 프롬프트, 최대 횟수, 임의 문장부호 금지 유지 |
| 금융 수치 | 의미 있는 물리 표면 | 결정론 Pillow/FFmpeg + 표면 binding | 유지하되 표면 의미 binding과 크기 예산을 강화 |
| 실제 기사/차트 | 캡처 삽입 | 일반 생성 이미지 중심 | 기사형 시각 모드의 선택 경로로 추가 검토. 출처·권리·해시 계보 필수 |
| 배경 선택 | 설명 기능별 다양한 유형 | V5 archetype·art direction 존재 | 폐지하지 않고 의미 기반 선택 정확도와 유형 범위를 보완 |

## archetype 권고

V5 archetype은 유지한다. 레퍼런스가 자유 혼합처럼 보여도 주된 설명 기능은 반복되는 유형으로 분류된다. 다만 현재 archetype 하나가 문자 정책·의상·표정까지 전부 고정하는 방식은 피하고 다음 축을 독립시킨다.

- 배경 archetype: 교실, 관제실, 공장, 시장 위기, 물리 은유, 증거 삽입 등
- 캐릭터 역할: 대본 상황에 맞는 의상·표정·행동, 얼굴/해부학 하한선은 공통
- 텍스트 라우팅: 하단 자막 / 짧은 생성 문구 / 결정론 정보 표면 / 실제 캡처
- 모델 선택: Pro/Flash 전체 비교 결과가 나온 뒤 유형별 근거로 결정

## 세 큰 목표와 연결

- 목표 1(분량·TTS·자막·이미지 싱크): 승인 내레이션을 하단 자막 SSOT로 유지하고, 이미지 한 장이 담당하는 청크의 핵심 의미만 배경 archetype과 소품에 배정한다.
- 목표 2(콘텐츠 의미 충실도): 추상 문장을 임의 차트 장식으로 채우지 않고 물리적 경제 은유 또는 증거 삽입형으로 연결한다.
- 목표 3(오탈자·이탈자·시각 품질): 긴 문자열은 별도 합성하고, 짧은 문구는 strict 게이트, 수치는 결정론 표면, 실제 증거는 캡처 계보로 분리한다.

이 분류는 Job52에만 붙는 패치가 아니라 공통 스크립트→이미지 표현 계약의 입력 자료다. 실제 운영 라우터 변경은 Pro/Flash 전체 결과 및 사용자 육안 판정과 함께 별도 최소 변경으로 진행한다.
