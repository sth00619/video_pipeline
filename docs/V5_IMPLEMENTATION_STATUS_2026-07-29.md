- 최종 배경 후보는 **Gemini 3 Pro Image**다. 단, strict_textless 오염 수정 검증이 끝날 때까지 최종 lane으로 확정하지 않는다.

## P3 품질 게이트

자동 판정은 비전 모델인 척 하지 않는다. 다음만 규칙 기반으로 차단한다.

- 16:9 종횡비 이탈
- 빈 배경 비율 과다
- 전체 윤곽·세부 묘사 부족
- 마스코트 외 소품 밀도 부족

캐릭터의 얼굴·손·정확한 면적과 AI 장식 텍스트의 자연스러움은 사람 검토 항목으로 남긴다.

현재 개발 환경에는 Tesseract·pytesseract·EasyOCR가 설치돼 있지 않다. 따라서 `8/8 자동 통과`는 텍스트 오염 해결과 무관하며, OCR 엔진 또는 별도 승인된 비전 판정이 연결되기 전에는 텍스트 누출에 대해 자동 통과를 줄 수 없다.

실패 장면은 재생성 예산이 있으면 정확히 한 번만 재시도한다. 두 번째도 실패하거나 예산이 없으면 빈 대체 이미지를 만들지 않고 `CutawayRequired`로 V4 cutaway 강등을 요청한다.

## 검증 사실을 장면에 넣는 계약

실제 대본 씬은 검증된 원문과 소품 표면을 함께 제공해야 한다.

```json
{
  "verified_facts": [
    {"fact": "검증된 원문", "figure": "검증 원문에 있는 값"}
  ],
  "v5_verified_overlays": [
    {
      "label": "표시 항목",
      "value": "검증 원문에 있는 값",
      "source_ref": "facts[0]",
      "anchor": {
        "x": 0.10,
        "y": 0.20,
        "width": 0.26,
        "height": 0.14,
        "kind": "monitor"
      }
    }
  ]
}
```

`value`가 `verified_facts[0]`의 `fact` 또는 `figure` 원문에 그대로 없거나, 출처·소품 좌표가 빠지면 렌더는 실패한다. 화면 모서리에 일반 정보 카드를 만드는 경로는 V5 최종 산출물에 사용하지 않는다.

## P4 라우팅 정책

```text
hero / body  -> Gemini 3 Pro Image 후보 lane (최종 승인 전에는 렌더 차단)
draft        -> BFL FLUX.2 klein
예산 부족    -> Gemini Pro에서 klein으로 한 단계 하향
둘 다 불가   -> 명시적 V4 cutaway 강등
```

Gemini Flash와 BFL Max/Pro는 동일한 V5 기준으로 재벤치마크하지 않았으므로 자동 선택하지 않는다. 외부 API 재시도는 요청 단위 비용 원장을 거쳐야 하며, Gemini의 실비는 콘솔 대조 전까지 `unverified_until_console_reconciliation` 상태를 유지한다.
