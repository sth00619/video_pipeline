# WO-IMG-01-C3 물리 표면 증명과 8장 측정 파일럿 게이트

작성일: 2026-08-27 KST

범위: 의미형 문자 표면의 오프라인 검증, Job52 표현 보존 조건, 다음 8장 파일럿 명세

실행하지 않은 단계: Gemini/Claude/Fal/Kling/TTS/영상 조립/썸네일

## 1. 결론

직전 문서의 두 번째 미완료 조건이던 **물리 표면 승인 연결은 축 정렬 단일 표면 범위에서 구현·검증됐다.**
`validated=True`나 호출자가 넣은 과거 attestation은 더 이상 승인 근거가 아니다. 최종 원본 이미지의 실제 픽셀과 SHA-256을 사용해 빈 내부, 기존 문자, 프레임 선, 사물·캐릭터 가림, 축 정렬 여부를 렌더 직전에 다시 검사한다.

사용자가 제안한 대로 다음 8장 파일럿을 **Job52 표현 보존 검토와 짧은 승인 문자 크기 실측을 함께 하는 파일럿**으로 설계하는 것이 맞다. 다만 이번 턴에는 실행하지 않았다. 현재 예약 회계 기준으로 8장 1회씩도 보수적 예약 상한이 `₩12,800`이므로, 과거 scene42용 `₩1,600/₩3,200` 승인과 별개인 새 총액 승인이 필요하다. 또한 파일럿 전용 짧은 승인 문자 선택 경로는 전역 정책으로 켜지 않고 명세에만 보류했다.

현재 판정은 다음과 같다.

| 조건 | 판정 | 범위/한계 |
|---|---|---|
| 실제 OCR 추세선 false negative | 합성 fixture 완료 | 실제 생성 이미지 표본의 재현율은 미측정 |
| 물리 표면 승인 | **단일 축 정렬 표면 완료** | 다중 별도 표면·원근 표면은 계속 차단 |
| 짧은 승인 문자 크기 | 파일럿 측정 명세 완료, 실행 전 | 8장만으로 전역 최소 비율 확정 금지 |
| Job52 표현 보존 | 파일럿별 DoD로 명세 | 실제 새 이미지 시각 판정은 아직 없음 |
| Fal | 보류 | 문자·수치 장면은 계속 모션 대상 제외 |

## 2. 확인한 원인과 수정

### 2.1 이전 계약의 실제 구멍

기존 `semantic_roles_v1`은 `surface_bindings[name]`의 bbox, 원본 해시, `validated=True`를 검사했다. 그러나 다음을 증명하지 못했다.

1. bbox가 실제 모니터·칠판·표지판 내부인지.
2. 내부에 생성 모델의 기존 글자나 숫자가 남아 있지 않은지.
3. 캐릭터·손·사물이 표면을 가리는지.
4. 단순 색상 사각형이 세트에 붙은 물리 프레임인지.
5. 기울어진 표면을 축 정렬 Pillow 렌더러로 그려도 되는지.

저장소에는 이미 OpenCV 기하 검출과 실제 Tesseract 무문자 검사가 있었지만, 새 의미형 렌더 경로는 이 결과를 호출하지 않고 호출자의 bool을 신뢰했다. 즉 검출 부품 부재가 아니라 **검출 결과와 최종 렌더 계약의 계보 연결 누락**이었다.

### 2.2 현재 계약

렌더 순서는 다음으로 고정했다.

1. 승인 대본 기반 문자열·수치 계약을 먼저 검증한다.
2. 표면이 하나이고 binding이 없을 때만 `detect_surface_local()`이 실제 이미지에서 후보를 찾는다.
3. 이 로컬 함수는 Claude/Gemini를 호출하지 않고 과거 vision 캐시도 사용하지 않는다.
4. contour가 패널 안쪽 프레임을 찾는 특성 때문에 폭·높이의 2%만 확장한다.
5. 확장된 bbox를 다시 실제 픽셀로 검증한다. 이 재검사를 통과하지 못하면 확장값을 쓰지 않는다.
6. 원본 SHA-256, crop SHA-256, 검출 quad, 전략·신뢰도, 프레임 밀도, 내부 채널 분산을 attestation에 보존한다.
7. 수치 오버레이 anchor가 검증 surface 안에 있는지 확인한다.
8. 임시 파일에 합성한 뒤 셀별 실제 bbox OCR이 모두 정확할 때만 원본을 원자적으로 교체한다.

다중 표면은 각 표면의 의미를 로컬 검출기가 추측하지 않는다. 명시 좌표가 모두 없으면 실패한다. 서로 다른 표면 bbox가 겹쳐도 실패한다. 원근 quad는 별도 warp·역변환 OCR 계약이 구현될 때까지 실패한다.

## 4. Job52에서 지켜야 할 표현과 이번 수정의 관계

이번 수정은 생성 프롬프트의 얼굴·의상·화풍·팔레트를 전역 변경하지 않는다. `channel_character_face_range_v1`과 Job52 문맥 참조 선택도 그대로 유지했다. 따라서 과거의 잘못된 대표 실험처럼 모든 장면을 같은 남색 진행자, 같은 얼굴, 같은 스튜디오, 같은 파란 카드로 수렴시키는 규칙이 아니다.

다음 파일럿은 다음을 장면별로 보존해야 한다.

- 숫자판보다 대사의 물리적 원인과 결과가 먼저 보여야 한다.
- 텍스트는 모니터·칠판·계기·표지판 같은 세트 소품 안에 있고, 화면 위에 붙인 일반 카드처럼 보이면 안 된다.
- 캐릭터는 동일한 금색 동전 종과 2D 잉크 언어를 유지하되 표정·모자·의상·위치는 장면 역할에 맞게 달라질 수 있다.
- scene02의 경찰 제복, scene08의 다른 캐릭터 종 같은 이탈만 막고 하나의 얼굴·의상을 복제하지 않는다.
- 두 팔·두 손, 계획 없는 말풍선 금지, 장면 로컬 허용 문자열 정확성은 시각 스타일 지시와 분리된 결과 게이트다.
- 경고의 적색, 회복의 녹색/금색, 불확실성의 청회색처럼 색이 의미를 나누되 전 장면에 하나의 팔레트를 강제하지 않는다.

## 5. 다음 8장 파일럿을 측정 실험으로 결합하는 안

[실행 명세 원문](evidence/wo_img01_c3_surface_binding_20260827/pilot-spec.json)은 Job52의 `00, 02, 05, 07, 15, 21, 35, 47`을 원인 유형별 기준으로 삼는다. 이 이미지를 재생성한다는 뜻이 아니라, 같은 장면 의미 유형을 새 입력에서도 재현할 수 있는 공통 경로를 시험한다는 뜻이다.

- 결정론 정보 lane 4장: 기업명·반도체·`4배`·`143조 원`·두 포인트 수치의 사실·위치·OCR 계약을 검사한다.
- 파일럿 전용 짧은 승인 문구 lane 4장: 대본에 실제로 있는 `경고`, `엇갈림`, `전망치`, `상반기 실적`, `질문`만 허용해 모델이 만든 짧은 문자의 크기와 오탈자를 측정한다.
- 짧은 문자 lane은 전역 허용이 아니다. 8장 결과에서 글자 bbox 높이/프레임 높이, PSM별 정확 판독, 임의 추가 문자열을 기록하기 위한 실험 선택 경로다.
- 8장 모두 표면은 정지 이미지에서 검증하며 Fal/Kling을 호출하지 않는다.

측정값은 `OCR bbox height / final frame height`로 원문 보존한다. 여러 PSM 중 하나만 맞는 결과를 골라 통과시키지 않고 판독별 결과를 따로 남긴다. 승인 문자열의 숫자·부호·단위·대소문자를 바꾸지 않는다. 8장에 오류가 0건이어도 전역 결함률이나 최소 문자 높이 X를 확정하지 않는다. 이전에 계산한 5% 결함률 상한 검증에는 더 큰 표본이 필요하다는 결론을 유지한다.

## 6. 비용과 중단 조건

현재 감사 원장은 실 이미지 시도당 `₩1,600`을 보수적으로 예약한다. 따라서:

- 8장 × 1회 = 예약 상한 `₩12,800`.
- 장면별 3회까지 허용하면 최악 예약 상한 `₩38,400`.
- 20분 미만 영상 전역 상한 `₩40,000` 안이지만, 3회 최악안은 다른 단계 여유가 `₩1,600`뿐이라 파일럿 계획으로 승인하면 안 된다.

scene42의 과거 두 503 예약은 청구 확정액이 아니지만, 그 승인 한도를 새 8장 명세에 임의 재사용하지 않는다. 다음 실행 전에는 **이 파일럿만의 총 예약 상한**을 사용자에게 명시해 승인받아야 한다. 추천은 8장 각 1회, 한 장이라도 공급자 503이 반복되면 나머지 요청을 쏟아붓지 않고 중단하는 방식이다. 성공 응답의 `usageMetadata`가 처음 잡히면 예상 비용 모델을 즉시 실측값으로 갱신한다.

## 7. Fal 및 3대 목표 상태

| 큰 목표 | 이번 작업 후 상태 |
|---|---|
| 1. YouTube·스크립트·TTS 시간 보정 | 변경 없음. 승인 내레이션·TTS·자막 입력과 해시를 수정하지 않았다. 신규 5분 SCRIPT/TTS E2E 완료를 주장하지 않는다. |
| 2. Fal/Kling 모션 | 문자·수치·정보 표면은 계속 fail-closed로 제외한다. 이번 8장도 정지 이미지 검증용이며 Fal로 넘기지 않는다. 나중에 텍스트 없는 초반 장면에서 캐릭터·사물만 움직이는 별도 파일럿이 필요하다. |
| 3. 이미지 문자·수치 정확성 | 상류 사실값 정확 대조, 셀별 위치/OCR, 추세선 간섭 제거에 이어 단일 물리 표면 픽셀 증명까지 완료했다. 실제 Job 스타일 분포와 짧은 승인 문자 크기는 8장 파일럿 측정이 남았다. |

따라서 다음 유료 단계는 Fal이 아니라 **8장 정지 이미지 측정 파일럿**이다. 다만 새 총 예약 상한 승인과 파일럿 전용 짧은 승인 문자 선택 경로가 준비되기 전에는 실행하지 않는다.
