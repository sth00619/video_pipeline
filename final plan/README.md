## 자산 (실제 파일 첨부)

```
assets/
├─ our_character/        ← 노란 코인 = 우리가 만드는 영상 캐릭터 (만족한 결과물)
│  ├─ 01_port_emergency_항구비상.png
│  ├─ 02_split_stage_무대비교.png
│  ├─ 03_retail_shock_마트쇼크.png
│  ├─ 04_weather_map_기상캐스터_v1.png
│  ├─ 05_weather_map_기상캐스터_v2.png
│  └─ 06_v5_primary_surface_pilot_아키타입비교.png
├─ reference_channel/    ← 초록 지폐 = 경제사냥꾼 레퍼런스 (목표 화풍/구도)
│  └─ ref_01 ~ ref_08 (.webp)
└─ samples/
   ├─ 선택음성_v7_question_tone.mp4   ← 3단계 TTS가 재현해야 할 목소리·억양
   └─ 만족한_fal_인트로_walking.mp4    ← 5단계 fal 인트로가 재현해야 할 모션
```

> 캐릭터 규칙: **노란 코인 = 우리 채널 캐릭터**(네이비 정장), **초록 지폐 = 레퍼런스 채널 캐릭터**.
> 우리 영상에는 절대 초록 지폐가 나오면 안 되고, 화풍·구도·배경 종류만 참고합니다.
