# 05. 썸네일 — 레퍼런스 채널 스타일 자동 추천

> 목표: **영상에 실제로 쓰인 이미지**로, 경제사냥꾼 스타일 썸네일을 자동 추천.
> 없는 수치·가짜 문구를 지어내지 않는다.

---

## 이미 존재하는 것 / 이번에 손댈 것 / 건드리지 말 것

| 구분 | 항목 |
|---|---|
| ✅ 이미 존재 | `_build_thumbnail_brief`, thumbnail **v2 계약**(`chart_warning`/`article_evidence` 템플릿), 내러티브 플랜(`build_from_video_manifest`), 에디토리얼 오버레이 |
| 🔧 손댈 것(요청 시) | 레퍼런스형 헤드라인 레이아웃 튜닝, source_scene_ids 선정 규칙 |
| ⛔ 건드리지 말 것 | 검증 배지 규칙(`source_ref` 없으면 배지 없음), 대본→씬 계보 |

---

## 1. 입력·출력 계약

- **입력:** 영상에 실제로 쓰인 씬 이미지(`source_scene_ids`) + `verified_facts`.
- **출력:** 썸네일 브리프(레이아웃 + 헤드라인 + 배지 + 소스 씬 id).
- **원칙:** 썸네일은 **영상에 등장한 이미지에서 파생**. 새 이미지를 위해 가짜 수치를
  만들지 않음. 배지는 **`source_ref`가 있는 검증값만**, 없으면 배지 없이.

---

## 2. 레퍼런스 썸네일 스타일 (초록 지폐가 정답)

`assets/reference_channel/`의 커버 프레임을 보면 공통 패턴이 있습니다:

- **큰 캐릭터 + 좌우 대비 무대**(예: CHINA vs KOREA), 또는 중앙 강조 소품.
- **헤드라인 2줄**: 흰색 기본 + **핵심 단어만 노란색 강조**(예: `차별적 대우`).
- 날짜/맥락 라벨(예: `2026 7월`), 우상단 채널 워터마크.
- 배지: 검증된 핵심 수치 1개(예: `12.5% CAP`) — 있을 때만.

우리 썸네일도 이 틀을 따릅니다(캐릭터만 노란 코인으로):

```
[헤드라인 1줄: 훅 — 흰색]
[헤드라인 2줄: "지금 확인할 " + "핵심"(노란 강조)]
[중앙/우측: 영상에 쓰인 대표 씬(노란 코인)]
[배지: 검증 수치 1개 — source_ref 있을 때만]
[우상단: 채널 워터마크]
```

---

## 3. v2 계약 템플릿 선택

| 템플릿 | 언제 |
|---|---|
| `chart_warning` | 검증 차트/경고 톤(기본 시작값) — 가짜 인물·기사 불필요 |
| `article_evidence` | 리뷰된 한국어 **기사형 근거 프레임**이 있을 때(플래너/게이트가 교체) |

- 배지 규칙(코드와 동일): `verified_facts`에서 **숫자가 있는 첫 `figure`**만 배지로,
  `source_ref = facts[i]`. 없으면 배지 생략.
- 헤드라인 강조 색(`tone: yellow`)은 **핵심 단어에만** — 레퍼런스의 노란 강조와 동일.

---

## 4. 소스 씬 선정 규칙

- 인트로 씬 + `data/scenario/action/conclusion` 역할 씬 중에서 **대표성 높은 3개**를
  `source_scene_ids`로. (영상에 안 쓰인 이미지 금지 — "영상 이미지로만 썸네일" 요구 충족)

---

## 완료 기준

- [ ] 썸네일이 **영상에 실제 쓰인 이미지**만 사용.
- [ ] 헤드라인 2줄 + 핵심 단어 노란 강조(레퍼런스 톤).
- [ ] 배지는 `source_ref` 있는 검증값만(가짜 수치 없음).
- [ ] 노란 코인 캐릭터, 우상단 워터마크, 초록 지폐 미등장.
- [ ] 레퍼런스 커버와 나란히 비교 이미지 첨부(추정 금지).
