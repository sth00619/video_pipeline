## 1. 캐릭터 해부 (초록 지폐)

**신체 규격**:
- 베이스: 1만원권 지폐(세종대왕 초상 노출)를 세로로 세운 직사각형 몸체
- 얼굴: 지폐 상단 2/3에 배치. 큰 원형 눈(흰자+검정 동공), 발그레한 볼, 넓은 입(말할 때 빨간 혀+흰 이 노출)

## 3. 프롭 위 텍스트 문법 (가장 중요)

레퍼런스의 **모든 화면 텍스트는 물리적 프롭 표면**에 배치됨. 공중에 뜬 UI 박스는 없음.

| 텍스트 유형 | 배치 프롭 | 예시 |
|---|---|---|
| 헤드라인 경고 | 컨테이너/박스 표면 | "PORT WARNING: SEVERE DELAYS" |
| 인증 도장 | 문서 위 빨간 잉크 도장 | "TARIFFS APPROVED" |
| 개념 라벨 | 칠판 다이어그램의 네모 박스 | "GLOBAL SUPPLY CHAIN", "TARIFFS", "HUMAN RIGHTS" |
| 검증 수치 | 계산기 LCD / POS LED | "1,125,000", "TOTAL: 1,125,000 KRW" |
| 관세율 | 무게추 표면 각인 | "Section 232 / Anti-Dumping" |
| 계약 수치 | 저울 위 금색 문서 | "15% Agreement" |
| 지도 오버레이 | 구름 그래픽 위 | "10% TEMPORARY TARIFF", "12.5%" |
| 스포트라이트 배지 | 우산/방패 위 | "12.5% CAP" |
| 수식 | 부동 (하지만 반투명 배경 격자와 결속) | "E_d = sin(in-b)² / (1-cost)" |
| 국기 라벨 | 스포트라이트 상단 큰 문자 | "CHINA", "KOREA" |

→ **"공중 UI 박스 절대 금지" 규칙은 이 문법과 완전히 일치**. 우리 `BASE_STYLE_LOCK_PROMPT`의 "NO readable text on non-primary props, NO UI panels" 유효.

**정확 수치 vs 근사 방향**:
- 정확 수치가 **화면의 주제**인 경우(예: "112만 5천원" 마트 계산): POS LED에 정확 렌더 → **결정론 Pillow 오버레이**
- 방향성만 필요한 경우(예: 상승/하락): 빨간 하강 그래프 아이콘 → **모델이 근사 렌더 OK**

→ 우리 `diegetic_fact_overlay.py` + `hero_stat_from_chart` 조합이 정확 수치 렌더 담당. 유효.

## 4. 자막(하단 스트립) 규격

**정확 측정** (ref_01, ref_02, ref_05, ref_07에서):

| 항목 | 값 |
|---|---|

| 배경 | **검정 반투명 바** (alpha ≈ 80~90%). 화면 전체 폭. 위쪽 경계 그림자 없음 |
| 텍스트 색 | **순백색** (#FFFFFF) |
| 폰트 | 굵은 산세리프 한글 (나눔스퀘어 Extra Bold 또는 Pretendard Black 계열) |
| 크기 | 화면 높이의 **약 4~5%** (720p 기준 32~36px) |
| 스트로크 | 검정 외곽선 얇게 (2px 미만) 또는 없음 |
| 한 줄 글자수 | **15~25자** (한 문장 = 한 라인) |
| 문장 종결 | 마침표/쉼표 유지 |
| 정렬 | 중앙 |
| **주의** | **자막 뒤에 별도 큰 검정 판을 씬 위에 오버레이하지 않음**. 하단 스트립만. |

## 5. 말풍선 (Speech Bubble) 문법

레퍼런스는 씬의 훅 순간에만 말풍선 사용 (모든 문장에 X):

**ref_01**: "이유가 뭘까?" — **레인보우 그라디언트**(빨강 상단 → 노랑 → 초록 → 파랑 하단), 두꺼운 검정 외곽선, 흰색 구름 배경
**ref_02**: "헐! 너무 비싸" — **순검정 굵은 텍스트**, 튀는 뾰족 구름(shock burst)
**공통**: 캐릭터 얼굴 옆(위/좌/우), 크기는 화면 가로의 **20~30%**

→ 우리 파이프라인은 현재 말풍선 **미구현**. 사용자 지침 "말풍선 절대 금지"와 충돌 여부 확인 필요:
- 사용자 실제 지침: *"이상한 말풍선과 수치를 설명하는 내용이 이미지 사이에 이상하게 등장하면 절대 안됨"*
- → **"이상한(정체불명) 말풍선 금지"**이지 **"말풍선 자체 금지"는 아님**. 씬의 캐릭터가 명확히 발화하는 훅 순간의 말풍선은 채널 그대로 재현 대상.

**해석**: 대본 씬의 첫 문장/훅 문장이 있을 때만 말풍선 활성. 씬 사이 유령 말풍선은 금지. → **오프션 구현 대상(선택형 훅)**.

- 우상단 워터마크: 항상 존재

**시선 유도**:
- 캐릭터의 지팡이/포인터가 항상 텍스트 프롭을 가리킴
- 화살표·번개·스포트라이트가 강조 대상 방향으로 흐름

**깊이감**:
- 3층 구조: 전경(캐릭터+주요 프롭) → 중경(스튜디오/무대 세팅) → 원경(배경 지역/스카이라인)

## 10. 스크립트↔이미지↔TTS 3자 결속 문법 (채널 관찰)

레퍼런스 영상에서 관찰된 결속 패턴:

**씬 = 화면 = 문장 3자 1:1 결속**:
- 한 씬(무대) → 한 스토리 비트 → **한 이미지** → **1~3개 낭독 문장 = 1~3개 자막 라인**
- 씬 지속: **평균 5~10초** (짧으면 3초, 훅 씬은 12초까지)

**리듬**:
- 훅 문장(질문형 `~까요?`) → 정지 이미지 유지 → 답 문장(설명형) → 그림 요소 하나 추가/강조
- 설명형 3연속 금지(우리 `flow_qa.py`와 일치)

**전환**:
- 컷 전환은 **하드 컷** (페이드 없음)
- 전환 시 새 무대로 완전 이동 (아키타입 리롤)
- 같은 무대(예: 교실)에 3씬 연속 붙지 않음 → 우리 `_rebalance_scene_type_distribution` 이 처리

**TTS 억양**:
- 질문 문장은 상승 억양
- 강조 어절은 살짝 톤 상승 (v7 IVC 목소리와 정합)
- 문장 간 짧은 호흡(70ms) — 우리 값과 일치
