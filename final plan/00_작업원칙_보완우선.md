# 00. 작업 원칙 — 「보완 우선」 (모든 작업의 최우선 명심 과제)

> 이 문서는 기능 명세가 아니라 **행동 규칙**입니다. 이 프로젝트에서 반복적으로
> 발생한 가장 큰 실패는 기술 부족이 아니라, **매번 기존 완성물을 무시하고 처음부터
> 다시 만들어 멀쩡하던 기능까지 부수는 것**이었습니다. 새 작업을 시작하기 전에
> 반드시 이 문서를 먼저 읽습니다.

---

## 0. 한 문장 원칙

**"새 수정·추가는 기존 작업물에 보완되는 형태로 얹는다. 충돌하거나 고쳐야 하는
부분만 손대고, 나머지 완성 기능은 그대로 흐르게 둔다."**

기존 작업을 통째로 버리고 새로 짜는 것은 이 프로젝트에서 **명백한 오작업**입니다.

---

## 1. 이미 완성돼 "흐르고 있는" 기능 (건드리지 말 것)

아래는 **이미 동작하는 파이프라인 골격**입니다. 새 작업이 이걸 대체하는 게 아니라
**이 위에 연결**되어야 합니다.

- ✅ **키워드 입력 → 후보 지표 선정(최고점) → 스크립트 생성 → TTS 생성 →
  일반형 이미지로 영상 이미지 생성 → 영상 조립(+fal 초반 활용) → 영상 이미지로 썸네일 제작**
  — 이 E2E 경로는 이미 존재합니다.
- ✅ 레퍼런스 스타일 대본 생성(3-Round 팩트체크, 검증 사실 기반)
- ✅ TTS 스크립트 100% 일치 생성 + 문자 단위 자막 정렬(Forced Alignment)
- ✅ 일반형 이미지 생성
- ✅ fal.ai 초반부 활용(인트로 모션)
- ✅ V5 walking skeleton + **11종 아키타입** + `korean_overlay.py`(Pillow) + Cost Ledger

**따라서 "기사형 이미지", "정보형(수치/그래프) 표현" 같이 요청받은 작업은,
위 완성 기능을 다 무시하고 새로 만드는 게 아니라, 해당 조각만 추가/보완해서
나머지에 연결하는 것입니다.**

---

## 2. 지금까지 실제로 일어난 오작업 (같은 실수 반복 금지)

E2E 테스트/작업에서 관측된, **하지 말아야 할** 패턴:

| 잘못된 행동 | 결과(증상) | 올바른 행동 |
|---|---|---|
| 정보형(수치·그래프) 넣어달라 했더니 기존 **V5·아키타입을 무시**하고 새 이미지 로직으로 재작성 | 이미지 전반이 깨짐 | V5 아키타입은 그대로 두고, 수치 "표현"만 오버레이/스타일로 추가 |
| 이미지에 그래프를 넣는다며 **UI 박스/카드**를 화면에 억지로 합성 | 그래프 대신 엉망 UI 박스가 박힘 | 결정론 렌더(matplotlib/Pillow)로 **소품 표면 안에만** 그리거나, 근사 표현(빨강↑/파랑↓)로 대체 |
| 자막을 새로 그리며 **검은 배경 박스** 추가 | 자막 뒤에 검은 배경이 튀어나옴 | 레퍼런스처럼 **하단 1줄 자막 스트립** 유지, 기존 ASS 렌더 그대로 사용 |
| "수치 설명" 말풍선을 이미지 사이에 삽입 | 이상한 말풍선·수치가 씬 사이에 등장 | 대본은 **자막의 유일한 원본**. 공중 말풍선·수치 카드 계획 금지(`script_caption_only_policy`) |
| TTS를 "다시" 만들며 스크립트 100% 일치 규칙 무시 | 음성과 자막이 어긋남 | 기존 Forced Alignment/문자 정렬 경로 유지, 텍스트 계약(SHA256) 검사 그대로 통과시킬 것 |

> 핵심: **요청한 것만 바꾸고, 요청하지 않은 완성 기능은 절대 재작성하지 않는다.**

## 3. 새 작업을 시작하기 전 자가 점검 (Codex 필수 선행)

작업 파일을 열기 전에 아래를 **실제 코드에서 확인**하고 시작합니다. (추정 금지)

1. **이 기능이 이미 있는가?** — `git grep`으로 관련 함수/모듈을 먼저 찾는다.
   - 예: 수치 오버레이 → `_attach_verified_index_overlays`, `_attach_verified_market_charts`,
     `hero_stat_from_chart`, `editorial_overlay`
   - 예: 씬 분류 → `_classify_scene_types`, `_rebalance_scene_type_distribution`
   - 예: 자막 정렬 → `_extract_timestamps_with_forced_alignment`, `_map_display_chunks_to_spoken_characters`
2. **어떤 함수 시그니처를 소비/변경하는가?** — 실제 시그니처를 인용한 뒤 수정한다.
3. **이 변경이 통과해야 할 기존 게이트는?** — 예: 키워드 커버리지, 단위 검증,
   TTS 텍스트 계약(SHA256), 씬 텍스트 근거 검증(`validate_verbatim`).
4. **이 변경이 깰 수 있는 인접 경로는?** — 순차 경로를 고치면 병렬 경로
   (`gemini_parallel_enabled=True`)에도 같은 수정을 반영한다.

## 4. 완료 기준 (증거 없는 완료 보고 금지)

- **단위 테스트 통과만으로 "완료" 주장 금지.** 반드시 **E2E 증거**(실제 실행 로그 +
  결과 이미지/영상 프레임)를 첨부한다.
- 완료 리포트에는 **실제 실행 로그**를 넣는다(추정·전망 문장 금지).
- 시각 결과물은 **레퍼런스(초록 지폐) 화풍과 나란히 비교**해서 첨부한다.

---

## 5. 절대 규칙 (프로젝트 전반, 이 세트 어디서든 유효)

- LLM은 `claude-sonnet-4-6` 고정 — **변경 금지**.
- 이미지는 **Nano Banana Pro(Gemini 3 Pro Image) 단일 모델** — Flash 강등 없음.
- **LLM/이미지 모델은 검증 수치를 만들지 않는다.** 지수·등락률·금액 등 모든 수치는
  `verified_data`에서 `source_ref` 추적성과 함께 흐르고, **한국어 텍스트·검증 숫자는
  Pillow 결정론 오버레이**로 렌더한다.
- `%` → `퍼센트`만. `포인트`는 지수·가격의 **절대 변동값**에만. (`1.2% ≠ 1.2포인트`)
- 모든 랜덤은 **씬 시드 기반 결정론** RNG.
- 실패는 **조용히 폴백하지 않는다.** 탐지 실패 → `DATA_CUTAWAY`, 폰트 하한 미달 →
  내용 거절(글자 축소 금지). ElevenLabs 실패 시 성우를 몰래 gTTS로 바꾸지 않고
  **게이트에 잡을 남긴다.**
- API 키 하드코딩 금지. JWT/DB/관리자 자격증명은 **환경변수 필수(미설정 시 기동 실패)**.
- 스타일 "차용"은 합법(아이디어-표현 이분법), **문장·시그니처 복제는 금지**.
- 캐릭터/스타일 프로필은 **채널별 격리**(크로스채널 스타일 블리드 금지).
