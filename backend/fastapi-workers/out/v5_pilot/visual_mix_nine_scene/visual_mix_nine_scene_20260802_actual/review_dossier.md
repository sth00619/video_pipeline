# 9장면 시각 믹스 파일럿 검수

## 판정

| 구분 | 장면 | 판정 | 근거 |
| --- | --- | --- | --- |
| 기사형 | 코스피 주간 전망 | PASS | 서로 다른 공개 원문을 사용하고, 검증 좌표를 기준으로 형광 하이라이트·빨간 밑줄을 결정론적으로 합성한다. |
| 기사형 | 미국 증시 뉴스 영향 | PASS | 원문 문장과 핵심 구절의 DOM 좌표가 검증됐으며 강조 효과를 적용한다. |
| 기사형 | 반도체 섹터 뉴스 | PASS | 원문 문장과 핵심 구절의 DOM 좌표가 검증됐으며 강조 효과를 적용한다. |
| 상황형 | 대형주·소형주 연관 | PASS | 교실 칠판의 연결 지도, 단일 페도라·슈트 캐릭터. |
| 상황형 | 미국 뉴스의 한국 영향 | PASS | 폭풍 항만·컨테이너·선박·신호등으로 상황을 표현한다. |
| 상황형 | 월간 변수 균형 | PASS | 위험 관제실의 우산·경고등·상자·계기판으로 균형을 표현한다. |
| 정보형 | 반도체 약세 | PASS | `SEMICONDUCTOR GOES DOWN` 문구가 스튜디오 스크린에 물리적으로 결합돼 있다. |
| 정보형 | 매수 신호 | PASS | `BUY SIGNAL` 문구가 대형 지도형 스크린에 결합돼 있고 상승·신호등 소품을 사용한다. 고정 캐릭터 모델시트 계약으로 재생성했다. |
| 정보형 | 공포 완화 | PASS | `FEAR IS COOLING` 문구가 중앙 아날로그 계기판 안에 한 번만 들어간다. 리포터 슈트·흰 장갑 계약으로 재생성했다. |

## 공통 계약 확인

- 굵은 검정 외곽선, 선명한 셀 셰이딩, 모자·슈트·홍조 캐릭터를 유지했다.
- 생성 장면 모두 캐릭터 머리장식은 한 개다.
- 정보형 영어 문구는 소품 표면에만 결합됐고, 금융 수치 오버레이는 사용하지 않았다.
- 상황형은 교실·항만·위험 관제실로 배경을 분리했다.
- 기사형은 생성 이미지가 아니라 검증된 출처 캡처다.

최종 선택 경로는 `final_selection.json`에 기록한다. Gemini 생성 비용은 콘솔 정산 전까지 추정치로만 관리한다.
